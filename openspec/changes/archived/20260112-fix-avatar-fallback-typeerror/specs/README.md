**閱讀順序**：
1. [Proposal](../proposal.md) - 了解問題
2. [組件規格](./components.md) - 理解架構
3. [實作規格](./implementation.md) - 開始編碼

**實作步驟**：
1. 建立 `lib/utils/avatar.ts`（複製實作規格中的程式碼）
2. 建立測試檔案（複製 27 個測試案例）
3. 執行測試確保通過
4. 修改 SalespersonCard（按照 Git Diff）
5. 重構 Header（按照 Git Diff）
6. 檢查其他頁面
7. 執行驗證清單

### 給 QA Engineer

**閱讀順序**：
1. [Proposal](../proposal.md) - 了解要修復的 bug
2. [實作規格](./implementation.md) - 跳到「驗證步驟」章節
